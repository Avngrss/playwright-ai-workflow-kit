[--with-browsers]`: the gate, each new or changed check proven able to fail, one run with `--retries=0` and the
stand's second pass, one block from the result files (`npm run verify -- --restore` after a run cut off). Then the
Allure report, one automatic heal after a fresh implement, the reviews (light for an edited test, full for a new one
— `/review` in a new chat) and a summary led by the verdict, its numbers from the verify block, one next command.

A named product or rule change → `/plan <plan path> — <what changed>` · one or two red tests → `/heal <spec>:<line> …`
· three or more, or a CI run → `/triage` (a run summary's last line names which).
