worklfow (файл)
 └─ jobs (задачи)
     └─ steps (шаги)
         ├─ setup (Node, deps, browsers, cache)
         ├─ run (playwright test + flags)
         └─ report (artifacts, traces, PR comments)

1. WORKFLOW (Корневой уровень)
on - push, pull_request, schedule, workflow_dispatch. Для E2E часто триггерят на pull_request + push в main
permissions - contents: read, checks: write (если планируете комменты в PR), actions: read
concurrency - group: ${{ github.workflow }}-${{ github.ref }} + cancel-in-progress: true (экономит минуты, отменяет устаревшие PR-сборки)
env - CI: true (GitHub ставит автоматически), PLAYWRIGHT_HTML_REPORT: playwright-report, TRACE: on-first-retry

2. JOBS (Playwright-ориентированные)
runs-on - ubuntu-latest — официально рекомендуемая ОС. Лучшая совместимость с браузерными зависимостями
strategy.matrix - browser: [chromium, firefox, webkit] или shardIndex: [1,2,3], shardTotal: 3
needs - Зависит от build/deploy. E2E запускают после успешного деплоя на staging
timeout-minutes - 20–40 (E2E медленнее юнит-тестов). Увеличьте при --retries или большом количестве тестов
continue-on-error - true → удобно для фолки-тестов: пайплайн не падает, но в отчёте видно failures
environment - staging / prod → привязка к Environment Variables & Protection Rules

3. STEPS (Ядро Playwright-пайплайна)
Step: Checkout - actions/checkout@v4 - Забирает код + LFS (если используете тяжелые фикстуры)
Step: Node Setup - with: { node-version, cache: npm } - Устанавливает Node + кэширует node_modules
Step: Install deps - npm ci - Быстрая, детерминированная установка зависимостей
Step: Browsers + System Libs - npx playwright install --with-deps - Скачивает браузеры и устанавливает системные зависимости (libgtk, libnss, fonts и т.д.)
Step: Cache browsers - path: ~/.cache/ms-playwright - Кэширует браузеры. Ключ должен включать playwright.config.ts + package-lock.json
Step: Run tests - npx playwright test --project=${{ matrix.browser }} --reporter=html,list --retries=2 - Запуск с фильтрацией по проекту, генерацией HTML-отчёта и авто-ретраями
Step: Upload report - with: { name: playwright-report-${{ matrix.browser }}, path: playwright-report/ } - Сохраняет HTML, скриншоты, видео, трейсы для скачивания
Step: (Optional) PR Comment - microsoft/playwright-github-action@v1 или кастомный скрипт - Публикует ссылку на отчёт прямо в Pull Request

4. CLI FLAGS & CONFIG ДЛЯ CI
--shard=X/Y - Распараллеливание тестов по джобам. Ускоряет запуск в 3–5 раз
--retries=N - --retries=2 - Автоматический перезапуск фолки-тестов. Экономит CI-время
--reporter=html,list - --reporter=html,list - list → консольный вывод, html → интерактивный отчёт
--project=browser - --project=chromium - Запуск только нужного браузера из playwright.config.ts
--grep="@tag" - --grep="@smoke" - Фильтрация по тегам. Полезно для pull_request vs nightly

5. КОНТЕКСТЫ & ПЕРЕМЕННЫЕ (Playwright)
${{ matrix.browser }} - chromium - Передаётся в --project для фильтрации
${{ vars.BASE_URL }} - https://staging.example.com - Передаётся в Playwright через baseURL или env
process.env.CI - true - Автоматически в GHA. Отключает анимации, включает headless
process.env.PLAYWRIGHT_HTML_REPORT - playwright-report - Путь к генерации HTML-отчёта
process.env.PLAYWRIGHT_SKIP_BROWSER_DOWNLOAD - 1 - Пропускает скачивание, если браузеры уже в кэше
$GITHUB_STEP_SUMMARY - echo "📊 [Report](...)" >> $GITHUB_STEP_SUMMARY - Выводит ссылки в summary-вкладку пайплайна

BEST PRACTICES ДЛЯ PLAYWRIGHT CI
✅ Кэшируйте браузеры: ~/.cache/ms-playwright + хэш от playwright.config.ts. Экономит 2–4 мин на запуск.
✅ Используйте --with-deps только при первом запуске или инвалидации кэша. В остальных случаях: npx playwright install + npx playwright install-deps отдельно.
✅ trace: 'on-first-retry' → идеален для CI: не забивает диск, но даёт отладку при падении.
✅ Запускайте матрицу по браузерам параллельно, а не последовательно.
✅ Не хардкодьте таймауты в тестах. Управляйте через test.setTimeout() или конфиг.
✅ Отделяйте smoke от regression: pull_request → --grep="@smoke", schedule/push main → полный запуск.
❌ Не используйте ubuntu-20.04: устарела, проблемы с шрифтами и SSL.
🔄 workflow_dispatch + inputs: удобно для ручного запуска против конкретного окружения.

name: Playwright E2E
on:
  pull_request:
    branches: [main]
  push:
    branches: [main]
  schedule:
    - cron: '0 2 * * 1-5' # Nightly regression
  workflow_dispatch:

permissions:
  contents: read
  checks: write

concurrency:
  group: ${{ github.workflow }}-${{ github.ref }}
  cancel-in-progress: true

env:
  CI: true
  PLAYWRIGHT_HTML_REPORT: playwright-report

jobs:
  e2e:
    name: E2E (${{ matrix.browser }})
    runs-on: ubuntu-latest
    timeout-minutes: 30
    strategy:
      matrix:
        browser: [chromium, firefox, webkit]
      fail-fast: false
    steps:
      - name: Checkout
        uses: actions/checkout@v4

      - name: Setup Node
        uses: actions/setup-node@v4
        with:
          node-version: 20
          cache: npm

      - name: Cache Playwright browsers
        uses: actions/cache@v4
        id: playwright-cache
        with:
          path: ~/.cache/ms-playwright
          key: ${{ runner.os }}-playwright-${{ hashFiles('playwright.config.ts') }}
          restore-keys: |
            ${{ runner.os }}-playwright-

      - name: Install dependencies
        run: npm ci

      - name: Install browsers & system deps
        run: npx playwright install --with-deps
        if: steps.playwright-cache.outputs.cache-hit != 'true'

      - name: Run Playwright tests
        run: npx playwright test --project=${{ matrix.browser }} --reporter=html,list --retries=2
        env:
          BASE_URL: ${{ vars.STAGING_URL || 'http://localhost:3000' }}

      - name: Upload HTML Report
        uses: actions/upload-artifact@v4
        if: always()
        with:
          name: playwright-report-${{ matrix.browser }}
          path: playwright-report/
          retention-days: 30
          if-no-files-found: warn

      - name: Publish to GitHub Checks (optional)
        uses: LouisBrunner/checks-action@v1.5.1
        if: always()
        with:
          name: Playwright ${{ matrix.browser }}
          status: ${{ job.status }}
          conclusion: ${{ job.status }}
          output: |
            {"summary":"E2E for ${{ matrix.browser }}", "text":"Download artifact for full HTML report"}
